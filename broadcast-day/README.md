# 새빛 방송국 · 방송 PD의 하루

처음 출연하는 보람 님에게 생방송 시작을 손 신호로 알려 주겠다고 약속한다. 리허설에서 구도·초점·소리를 맞춘 다음 속보가 들어오면 인터뷰 시작을 누가 맡을지 결정한다. 그날의 선택에 따라 퇴근 전 대화와 기록이 달라진다.

## 직접 조작

- 카메라 손잡이를 밀어 얼굴을 담고 초점 링 가장자리를 둥글게 돌린다. 확인 버튼은 모니터의 구도와 초점을 함께 검사한다.
- 서로 다른 두 목소리와 배경 선율을 들으며 은색 페이더 세 개를 위아래로 민다. 소리를 끈 상태에서도 미터로 같은 작업을 할 수 있다.
- 큐에 맞는 카메라를 미리 고른 뒤 TAKE로 송출한다. 첫 장면·인터뷰·손 클로즈업을 거쳐 이름 자막을 올린다. 큐를 놓치면 진행자가 기다린 시간이 더해진다.
- 세 컷을 시장·인물·손 순으로 트랙에 놓고 자르기 도구를 누른다. 마지막 12초의 확대 눈금에서 칼날을 옮겨 30초에 놓는다.

## 실행과 통합

정적 파일은 `dist/`에 있다. 저장소 루트에서 `python3 -m http.server 8000` 실행 후 `/broadcast-day/dist/`를 연다. 통합 담당자는 dist 내용을 운영 경로 `/broadcast-day/`로 복사하고 `broadcast-producer` 도장을 연결한다. WebGL을 사용할 수 없는 기기는 SVG 투영으로 같은 모델을 조작한다. `?view=flat`으로도 검사할 수 있다.

`day.mjs`가 일정과 급여·기록, `studio.mjs`가 방송국과 이동, `hands.mjs`와 `feed.mjs`가 장비와 모니터 영상을 담당한다. 두 가상 인물의 대사는 로컬 한국어 합성 음성으로 제작했다. 음향은 사용자가 듣기를 눌렀을 때만 재생하며 작업대를 떠날 때 정지한다.

## 자료와 검사

[커리어넷 방송연출가](https://www.career.go.kr/cloud/w/job/view?seq=301) 직업 코드 301의 시리즈 수록 자료(워크넷 2021, 연 4,500만 원)를 공통 급여 산식에 넣는다. [방송심의에 관한 규정](https://www.law.go.kr/admRulLsInfoP.do?admRulSeq=2200000108985)의 객관성과 사생활 보호 원칙을 제보 확인과 리허설 사용 판단에 연결했다.

`node broadcast-day/tests/contract.mjs`로 기록·급여·교사 코드 계약을 확인한다. Playwright Chromium 준비 후 `BROADCAST_URL=http://127.0.0.1:8000/broadcast-day/dist/ node broadcast-day/tests/day-browser.cjs`로 휴대폰 세 크기와 데스크톱에서 하루를 조작한다.
