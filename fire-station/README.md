# 함께 돌아오는 하루 — 소방서

공통 직업체험 약속과 디자인 v1에 맞춘 새 일터입니다. 3D 소방서·훈련장·현장 지원 구역과 손으로 하는 작업, 앞선 선택의 후속 결과, 휴식·인계·퇴근·기록 내보내기를 제공합니다.

## 실행

저장소 루트에서:

```sh
python3 -m http.server 8080 --directory fire-station/dist
```

http://localhost:8080 을 여세요. 스마트폰에서는 같은 네트워크의 컴퓨터 IP:8080으로 접속합니다. 빌드/패키지 설치가 필요 없습니다. `?flat=1` 또는 ‘평면 모드’ 버튼은 WebGL 없이 같은 터치 작업을 사용합니다. HTML 더블클릭 대신 HTTP로 실행하세요.

## 조작과 하루

바닥 터치로 내 캐릭터를 움직입니다. 장비 세 개를 이름표에 끌어 놓고 차량을 점검한 뒤, 동료와 역할을 정합니다. 훈련 표적 위에서 누른 채 움직여 물줄기를 조절합니다. 휴식 후 현장으로 이동해 기다리는 사람에게 설명하고 표지를 옮깁니다. 복귀하면 손가락이 지난 곳의 먼지만 지우고 기록을 남깁니다. 밀린 일이 있으면 연장/인계를 고릅니다.

오전 역할 확인을 미루면 출동 때 10분이 추가됩니다. 자세한 설명과 기록은 안심·협업을 높이지만 시간이 듭니다. 실수는 점수 차감 대신 지연으로 표현합니다. 실제 화재 진압·구조 절차나 소방공무원의 실제 보수 계산을 가르치는 앱은 아닙니다.

## 검사

Node.js 22 이상:

```sh
node fire-station/tests/day.mjs
node fire-station/tests/hands.mjs
```

32가지 선택 조합의 끝까지 진행, 재진입 방지, 근무 시간·급여·연장 상한, 흥미 유형, 기록/교사 코드 호환성, 실제 문지름·드래그 취소·빈 움직임을 검사합니다. 2026-11-16 모바일 앱 브라우저에서 하루 전체를 실제 터치로 완료하고 기록 저장/보내기 진입까지 확인했습니다. PC 가로 배치와 평면 모드 시작도 확인했습니다. 힘 중복 차감 수정 후 관련 자동 검사를 재실행했습니다.

## 자료와 공통 계약

- 커리어넷 소방관 코드 **385**. 저장소 `career-day/src/data/careernet.js`의 2026-11-13 수집 자료를 사용합니다. 연봉 중앙값 **4,000만 원**, 원출처 **워크넷 2021년 소방관**.
- [커리어넷 직업정보](https://www.career.go.kr/cloud/w/job/view?seq=385), [2021년 임금 중앙값을 제시한 대입정보포털](https://www.adiga.kr/jbp/jnf/jobInfoDetail.do?menuId=PCJBPJNF2000&searchCrCd=240201&searchCrSeClsfCd=240).
- `salaryDay()`로 시급 **15,950원**, 8시간 기본급 **127,600원**을 계산합니다. 09:00–18:00, 휴식 60분의 공통 체험 일정이며 실제 교대·당직 시간표가 아닙니다.
- 쉬는 시간 일부를 일하면 그 시간도 급여에 포함합니다. 공통 검사의 연장 상한(120분)을 지키도록 휴식 근무와 퇴근 후 연장의 합을 제한합니다. 남는 지연은 인계합니다.
- shared의 workday.js / collect.js / design.css를 그대로 복사했습니다. 소방서 강조색은 #d2553f, 제목·버튼은 Jua, 본문은 Gowun Dodum입니다. Google Fonts를 읽을 수 없으면 시스템 글꼴로 동작합니다.
- 기록은 `app: fire-station`, `place: fire-station`, `job.id: firefighter`, `job.careernet: 385`. 공통 localStorage 지갑과 WD1 교사용 코드에 호환됩니다. 교사 화면은 기존 career-day의 것을 사용합니다.

## 파일

| 파일 | 역할 |
|---|---|
| dist/day.mjs | 하루 상태, 판단 결과, 시간/일당, 실제 순간 기록, 얼룩 상태 |
| dist/app.mjs | 명찰/HUD/작업/돌아보기/저장 UI |
| dist/world.mjs | Three.js 소방서·훈련장·현장, 차량·인물·바닥 터치 이동 |
| dist/hands.mjs | Canvas 2D 직접 조작: 드래그·점검·물줄기·문지름 |
| dist/send-records.mjs | 기존 바리스타 보내기 화면 재사용, 번호/이름 임시 입력 |
| dist/shared/ | 공통 파일 동일 복사본 |
| dist/vendor/ | Three.js와 원본 라이선스 |

## 통합과 현재 한계

`dist/`를 같은 origin의 `/fire-station/`에 배치하면 기존 두 앱과 지갑을 공유합니다. 그 경로로 열었을 때만 `../` ‘다른 일터 고르기’ 링크가 보입니다. 2026-11-16 사용자의 후속 통합 요청에 따라 workday-site의 허브 카드와 묶기 스크립트에 소방서를 연결했습니다. node workday-site/build.mjs로 public/fire-station/까지 생성하며, --check로 소스와 비교합니다. Claude에게 변경 범위를 게시판에 남겼습니다. 아직 Claude 브랜치에 병합하거나 공개 배포하지 않았습니다.

작업 클로즈업은 3D 위의 2D 터치 보드입니다. 3D 일터에서 공간 이동/장면 전환/인물 만남은 보이지만 손에 장비를 쥐는 3D 애니메이션, 실제 차량 주행, 정교한 구조 동작은 아직 없습니다. 진행 중 저장은 없으며 새로고침하면 하루가 초기화됩니다. 완료 기록만 남습니다. 실제 스마트폰 여러 기종, 키보드만으로 모든 손작업 완료, 화면 낭독기의 Canvas 대체 조작은 추가 검증/개선 대상입니다.
