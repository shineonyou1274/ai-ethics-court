# 운영 전 한 바퀴 더 · 우주항공

요청은 통합 브랜치 게시판 28e397c, 확인한 최신 통합 상태는 6b59988입니다. 작업 브랜치는 `codex/aerospace-story`입니다. 운영 배포·PR 병합 없음. `shared/`, `career-day/`, 사이트 첫 화면·빌드 스크립트는 변경하지 않았습니다.

## 바뀐 하루

학생은 지상 시험동을 걸어 도면의 간섭을 찾고, 조립대 위 도킹 링을 별 순서로 조이고, 센서의 역할을 읽어 직접 붙입니다. 두 번의 조종 시험을 비교해 15시에 진행/보류를 판단하고, 16시 가로 관제 창에서 접근·접속 또는 안전 후퇴를 끝까지 본 뒤 결과를 확인합니다. 실수 때문에 늘어난 재확인 시간은 즉시 표시되고 퇴근 선택과 기록까지 이어집니다.

## 검증 방법과 범위

항목별 고정 판을 별도 주소에서 검증합니다. 실제 CDP 터치 down/move/up, PC mouse down/move/up을 사용하고, 원 그리기·센서 들고 이동하기 중간에도 사진을 찍습니다. DOM의 화면상 입력 요소를 이용하며 게임 상태 주입·3D 객체 좌표 조회는 하지 않습니다. 실제 iPhone 하드웨어 검사와는 구분합니다.

폰 390×844, SE 375×667, PC 1280×800(동작 줄이기), 평면 320×568. 모든 장면 가로 밀림·앱/콘솔/HTTP 오류를 검사하고, 전체 뷰포트 영상(폭 320px 축소)에 공통 flicker 도구를 적용합니다. 사진은 원래 해상도입니다. 기준판은 7ad76de입니다.

공통·바리스타·우주항공 모델/통합 검사 및 생성 파일 65개 원본 일치를 확인했고, 병원·소방서 `npm test`도 통과했습니다. 볼트/센서 재확인 시간은 같은 실수 반복·취소·이미 연결한 센서에서 중복되지 않는 단위 검사를 추가했습니다.

최종 제품 소스는 `cf09e70`입니다. 영상 프레임 검토에서 발견한 화면 크기 변경·비동기 모듈 로딩의 빈 무대는 `18b2b23`/`cf09e70`으로 고쳤습니다. [전환 전후 프레임](review/2026-11-20/preflight/resize/README.md)을 보존했습니다.

최신 통합 브랜치 `6b59988`과 최종 제품 소스를 임시 트리로 합쳐 충돌이 없음을 확인했습니다. 실제 브랜치/PR을 합치지는 않았습니다. 그 임시 트리에서도 공통·병원/소방서·바리스타·우주항공 검사와 생성본 65개 일치 검사를 통과했습니다.

항목별 결과는 [BOARD](BOARD.md), 최종 전후 사진·전체 입력 기록·영상 분석은 [최종 검증 자료](review/2026-11-20/preflight/final/README.md)에 모았습니다.

## 표시를 잠시 감추는 이유

16시의 최종 결과 문장과 보고는 장면 종료 전에는 아직 관측하지 않은 결과이므로 표시하지 않습니다. 진행 중에는 제목·상태 안내가 계속 보이며, 종료 뒤 결과와 보고가 나타납니다. 동작 줄이기에서는 최종 정지 상태를 바로 보여 줍니다. 다른 장소 표시·안내·되돌아가는 길은 제거하지 않았습니다.

## 통합 담당에게

기존과 같은 직업 ID·임금·저장 구조를 유지합니다. 기록 extra에 boltRecheckMin/sensorRecheckMin을 추가했습니다. 잘못 연결한 조합의 내부 Set은 저장하지 않습니다. 새 파일은 `docking-bench.mjs`와 `station-labels.mjs`이며 앱 생성본에도 포함했습니다. 통합 브랜치에서 독립 재채점하고 다른 일터·네 입구·출근 기록을 확인해 주세요. 사용자 승인 전 운영 배포·PR 병합은 하지 않습니다.

센서 배치와 볼트 순서·도킹 수치는 직접 만든 교육용 모형입니다. 실제 항공우주 장비의 정비 절차를 가르치는 자료가 아닙니다.
