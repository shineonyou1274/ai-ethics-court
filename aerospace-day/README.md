# 오후 4시, 무인 화물선 도킹

항공우주공학기술자가 지상 시험동에서 도킹 장치를 준비·조립·시험하고, 오후 4시 접근을 진행할지 판단하는 교육용 하루입니다. 내 캐릭터로 다섯 작업 자리를 오가며 무전으로 들어온 일을 손으로 처리합니다. 비행기 풍동 시험이나 우주비행사 임무가 아닙니다.

작업 브랜치는 `codex/aerospace-story`입니다. 통합 요청은 `claude/integrate-fire`의 `1df6fdb` 게시판을 기준으로 합니다. 운영 배포·PR 병합은 하지 않습니다.

## 실행

저장소에서 `node workday-site/build.mjs` 후 `python3 -m http.server 8123 --directory workday-site/public`을 실행하고 `/aerospace-day/`를 엽니다. 파일 더블클릭 대신 HTTP 서버를 사용하세요. `?flat=1` 또는 평면 모드 버튼으로 같은 하루를 진행합니다.

## 하루와 직접 하는 일

| 시각 | 자리·일 | 내가 하는 것과 결과 |
| --- | --- | --- |

| 09:30 | 도면 책상 | 여섯 부품 가운데 겹치는 세 곳을 찾아 빨갛게 표시. 잘못 고른 곳은 이유를 읽고 재확인 2분, 같은 곳 중복 벌칙 없음 |
| 10:30 | 조립대 | 여섯 볼트를 1→4→2→5→3→6 순서로 손가락으로 돌리기. 틀린 순서는 막고, 조이면 주황색 틈이 닫힘 |

시험 실패·중지는 추가 시간이 없습니다. 조립을 끝내지 않고 넘기면 15분을 그 자리에서 알립니다. 도면 재확인 시간과 합쳐 위쪽 시각 및 퇴근 선택에 반영합니다. 진행을 골랐더라도 조립·센서·시험 조건이 맞지 않으면 관제가 안전하게 접근을 멈춥니다. 보류는 실패가 아닌 판단입니다.

## 화면과 기록

- 다섯 자리 표시나 걷기 버튼을 누르면 내 캐릭터가 가구를 피해 이동합니다. 바닥을 눌러 둘러볼 수도 있습니다. 새 무전은 해당 자리에도 표시합니다.
- `지상 시험동` 표시는 하루 내내 유지합니다. 손 장면은 확대된 작업 화면을 쓰며, 긴 설명·조작 버튼은 화면 아래에 놓습니다. 작은 폰은 아래 영역을 스크롤할 수 있습니다.
- 3D↔평면 전환은 위치와 작업 기록을 유지합니다. 동작 줄이기는 반복 움직임을 멈추고 관제 접근 장면을 최종 상태로 보여 줍니다.
- 다른 탭에서 출근자가 바뀌면 진행·저장을 막습니다. 새로고침하면 진행 중 하루는 사라지며 완료해 저장한 기록만 남습니다.
- 현재 사용자 기록·지갑·교사 코드 내보내기, 돌아보기 순간 카드 여덟 개를 유지합니다.

## 임금 기준

커리어넷 151의 워크넷 2021 항공공학기술자 연봉 중앙값 5,450만 원을 사용하는 기존 공통 기준입니다. 시급 21,730원, 기본 8시간 일당 173,840원을 변경하지 않았습니다. 큰 일당 아래 공통 `PAY_NOTE`를 항상 표시합니다. [직업정보 출처](https://www.career.go.kr/cloud/w/job/view?seq=151).

## 코드와 검사

- `dist/model.mjs`: 하루 순서·판단·시간·일당·기록.
- `dist/world.mjs`, `navigation.mjs`, `person.mjs`: 다섯 자리, 공통 비율의 내 캐릭터, 이동·평면 대체.
- `dist/task-data.mjs`, `task-world.mjs`, `task-ui.mjs`: 도면 간섭 찾기와 센서 끌어 붙이기.
- `dist/space-model.mjs`, `space-world.mjs`, `space-ui.mjs`: 준비·별 순서 조임·설계·도킹 조종.
- `dist/control-ui.mjs`, `report.mjs`: 관제 재현과 실제 시험 비교표.
- `dist/app.mjs`: 무전·화면 전환·세션·저장·교사 내보내기.
- `dist/fonts.css`, `fonts/`: 공통 디자인과 같은 Jua·Gowun Dodum을 자체 포함. 외부 글꼴 연결 없이 로드하며 OFL 라이선스·원본 출처를 함께 둡니다.

`node aerospace-day/tests/model.mjs`, `navigation.mjs`, `space.mjs`, `integration.mjs`, `send-records.mjs`는 모델·경로·시험·통합·세션을 검사합니다. `node shared/test.mjs` 및 `node workday-site/build.mjs --check`로 공통 약속과 묶음 일치를 확인합니다.

`tests/story-browser.cjs`는 Playwright로 실제 터치 이동·원 그리기·센서 끌기·조종간·슬라이더·저장을 수행하며 전체 화면 영상을 남깁니다. `BASE_URL`, `PROFILES=phone,se,pc,flat`, `DOCK=1`로 대상과 성공 도킹 경로를 선택할 수 있습니다. 게임 내부 상태를 주입하거나 3D 좌표를 조회하지 않습니다. 영상은 `node shared/tools/flicker.cjs <영상>`으로 별도 검사합니다.

기존 풍동용 `.cjs` 검사는 새 하루의 통과 근거가 아닙니다. **검증 완료 범위·커밋·전후 사진·남은 확인은 [BOARD](BOARD.md)의 최신 기록을 기준으로 합니다.** 구현 완료와 직접 조작 검증 완료를 구분합니다.
