## 실행

저장소 루트에서 `python3 -m http.server 8080 --directory aerospace-day/dist`를 실행하고 localhost:8080을 엽니다. 설치나 빌드가 필요 없습니다. `?flat=1` 또는 평면 모드 버튼으로 WebGL 없이도 같은 설계·시험·기록을 진행합니다. 파일 더블클릭 대신 HTTP 서버를 사용하세요.

## 직접 하는 일

- 터치 조절 막대로 날개 길이·각도·배터리 위치를 바꾸면 3D 시험기가 즉시 변합니다.
- 시험 중 바람 줄기와 흔들림이 나타납니다. 네 결과 지수와 매회 설계·바람을 표로 남깁니다.
- 오전 잔잔한 바람에서 두 번 이상 비교하고, 오후에는 옆바람에서 한 번 이상 확인합니다. 오전 최대 7회/하루 최대 8회로 오후 시험 자리를 남깁니다.
- 추가 시험과 빠른 탐색 계획에는 정리 시간이 따릅니다. 남아서 마치기/인계를 직접 고르며, 연장은 공통 120분 상한을 지킵니다.
- 7개 순간, A/R/I/E/S/C 유형을 돌아보고 출근 기록을 저장합니다. 이름은 내보내기 대화상자에서만 입력합니다.
