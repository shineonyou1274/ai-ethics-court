# 전환 영상에서 발견한 빈 프레임과 수정

전체 UI의 깜박임/흰 프레임 검사만으로는 푸른 빈 캔버스를 잡지 못했습니다. a41a3f3의 영상을 0.2초마다 펼쳐 실제로 확인하면서 15시 화면 크기 변경의 빈 프레임을 찾았습니다. 18b2b23에서 크기 변경 직후 동기 렌더링으로 고쳤습니다.

그 다음 18b2b23 영상에서 조종석 모듈을 비동기로 불러올 때 기존 무대가 먼저 사라지는 별도 전환을 발견했습니다. cf09e70은 다음 모듈 준비와 첫 그리기까지 기존 장면을 유지합니다.

최종 cf09e70 폰 전체 영상에서 준비·도면·조립·센서·설계·조종·결과·15시·관제 접근·관제 결과·보고·명세서의 12개 전환을 0.2초 간격으로 펼쳐 확인했습니다. 위 두 문제 구간은 25fps로도 확인했고 빈 무대를 발견하지 않았습니다. 이는 해당 기록에서의 확인이며 모든 기기의 모든 프레임을 보증하지 않습니다. 추출 시점은 windows.json, 원본 전체 영상은 로컬 outputs/preflight-round/transition/phone/에 있습니다.
