# 오늘, 출근합니다 (career-day)

직업인의 하루를 직접 판단하며 살아 보고, 퇴근하면 그날의 일당을 받는 진로 체험 앱이에요.
빌드하면 `career-day.html` 한 파일이 나와서, 그 파일만 나눠 주면 돼요.

```bash
npm install
npm run dev     # 고치면서 보기
npm test        # 모든 직업의 모든 길을 끝까지 돌려 보는 검사
node ../shared/test.mjs   # 앱끼리 함께 지키는 약속 검사
npm run build   # career-day.html 만들기
```

## 들어 있는 일터와 직업

| 일터 | 직업 | 일터 색 |
|---|---|---|
| 🏥 모아 병원 (`hospital`) | 의사 · 간호사 · 임상병리사 · 방사선사 · 원무행정 직원 · 약사 · 물리치료사 · 환경미화 직원 | `#dc795e` |
| 🚒 다솜 소방서 (`fire-station`) | 소방관 (커리어넷 385) | `#d2553f` |

첫 화면에서 일터를 고르면 그 일터의 3D 모형과 직업 도장 카드가 나와요. 주소 끝에 `#fire-station` 처럼 일터 이름을 붙이면 그 일터부터 보여요.

## 하루의 구조

| 장면 | 하는 일 |
|---|---|
| 명찰 | 커리어넷의 "하는 일", 근무 시간, 시급 |
| 탈의실 | 근무복으로 갈아입기 (3D 캐릭터 옷이 바뀜) |
| 기록 | 카드를 눌러 오늘의 기록 펼치기 |
| 첫 만남 · 팀 · 쉬는 시간 · 돌발 | **결과가 이어지는 판단** (게이지 셋과 밀린 시간이 바뀜) |
| 순서 맞추기 | 일의 순서를 손으로 맞추기 (틀리면 시간이 듦) |
| 골라 담기 | 인계·확인할 것 고르기 (사실과 짐작, 개인정보) |
| 남은 한마디 | 앞선 선택에 따라 다른 말을 들음 |
| 퇴근 | 밀린 일이 있으면 남아서 마칠지(연장 수당) 넘길지 |
| 일당 명세서 → 퇴근길 돌아보기 | 끌린 순간·버거운 순간 → 흥미 유형 |

- 게이지: 🫶 안심(만나는 사람) · 🤝 호흡(동료) · 🔋 에너지(나)
- **밀린 시간**: 판단에 따라 일이 밀리면 시계가 늦어지고, 3D에 기다리는 줄이 생겨요.
- **여파(ripple)**: 앞의 선택이 뒤 장면에서 다시 나타나요. 예: 간호사가 "다시 오겠다"고 약속하고 일이 밀리면, 오후에 그 말을 다시 들어요.

## 손으로 하는 장면 (`src/hands/`)

판단만 고르는 게 아니라 손으로 직접 해 보는 장면이에요. 여덟 직업 모두 들어 있어요(의사는 넷, 나머지는 하나씩).

### 의사 시험판

| 시각 | 장면 | 손으로 하는 일 | 결과가 이어지는 곳 |
|---|---|---|---|
| 08:12 | 손 위생 | 손 그림 위의 균을 여섯 단계로 문질러 지우기. 중간에 서둘러 나갈 수 있음 | 서두르면 병실 앞에서 손 소독을 한 번 더 함 |
| 08:18 | 환자 확인 | 침대 셋 가운데 팔찌를 읽어 이름과 생년월일이 모두 맞는 분 찾기 (이름이 같은 분, 생년월일이 같은 분이 섞여 있음) | 잘못 짚으면 다시 확인하느라 시간이 듦 |
| 09:10 | 수술 준비 | 모자·마스크 → 손 세척 → 가운 → 장갑을 끌어다 입기, 팀과 타임아웃 | 순서가 엇갈리면 팀이 기다림 |
| 09:55 | 봉합 | 위 점에서 아래 점까지 끌어 다섯 땀 꿰매기 | 많이 놓치면 다시 꿰매느라 시간과 힘이 듦 |

### 3D 일터에서 직접 닦고 옮기기 (`src/world/closeup.js`)

바리스타의 테이블 닦기처럼, 3D 화면이 일터 가까이 내려가고 학생이 3D 위를 손가락으로 직접 문지르거나 물건을 집어 옮겨요.

| 직업 | 장면 | 손으로 하는 일 | 판단이 갈리는 곳 |
|---|---|---|---|
| 환경미화 직원 | 로비 바닥이 젖었어요 | 노란 안내판을 끌어 세우고, 대걸레로 물웅덩이와 물자국을 문질러 닦기 | 안내판 없이 닦기 시작하면 지나가던 분이 미끄러질 뻔함 |
| 간호사 | 퇴원한 자리를 다음 분을 위해 | 쓴 시트를 세탁함에 끌어 넣고, 매트리스를 소독 티슈로 문지르고, 새 시트를 끌어 깔기 | 소독 전에 새 시트를 깔려 하면 막히고 시간이 듦 |
| 임상병리사 | 검체가 들어왔어요 | 튜브를 뚜껑 색이 같은 칸에 꽂고, 흘린 시약 닦기 | 다른 칸에 꽂으려 하면 다시 확인하느라 시간이 듦 |
| 방사선사 | 다음 분이 눕기 전에 | 촬영대를 닦고, 종이 커버를 깔고, 자세 받침 놓기 | 닦기 전에 커버를 깔려 하면 막힘 |
| 물리치료사 | 치료를 마친 자리 | 매트를 닦고, 바닥의 공·밴드·아령을 정리대 제자리에 놓기 | 자리를 헷갈리면 다시 놓느라 시간이 듦 |

### 소방관 (다솜 소방서)

오전에는 살피고 준비하고, 오후에는 출동하고 돌아와 다시 준비해요. 손으로 하는 장면 넷 모두 3D 가까이 보기예요.

| 시각 | 장면 | 손으로 하는 일 | 판단이 갈리는 곳 |
|---|---|---|---|
| 09:12 | 교대 점검, 장비는 제자리에 | 헬멧·공기호흡기·랜턴을 소방차 장비함의 이름표가 같은 칸에 끌어 싣고, 차고 바닥 물기 닦기 | 다른 칸에 실으려 하면 다시 확인하느라 시간이 듦 |
| 10:40 | 물줄기를 표적에 | 호스 펴기 → 관창 끼우기 → 소화전 열기. 물이 나오면 표적의 불꽃 표시를 문질러 지우기 (물줄기가 손가락을 따라옴) | 관창보다 소화전을 먼저 열려 하면 막히고 시간이 듦. 물이 나오기 전에는 지워지지 않음 |
| 14:38 | 출동! 골목에 불이 났어요 | 안전선 세우기 → 호스 끌어오기 → 물줄기로 불 끄기(불꽃이 지운 만큼 작아짐) → 탄 상자 걷어 내기 → 속에 남은 불씨까지 끄기 | 안전선보다 호스를 먼저 놓으려 하면 막히고 시간이 듦. 불꽃이 사라져도 불씨를 끄기 전에는 연기가 계속 남 |
| 15:35 | 돌아오면, 다음 출동 준비 | 방화복 그을음 닦기 → 다 쓴 공기통을 충전대로 → 채운 공기통을 차에 싣기 | 그을음을 닦기 전에 공기통을 만지려 하면 막힘 |

- 판단 장면: 시장 소방시설 점검에서 만난 상인(설명·안내문·다시 오겠다는 약속), 훈련 뒤 정비를 언제 할지, 불을 끈 뒤 현장에서 무엇을 맡을지, 출동 기록에 무엇을 적을지.
- 여파: 정비를 점심 뒤로 미루면 출동이 늦어지고, 먼저 해 두면 바로 나가요. 오후에 다시 오겠다는 약속은 출동과 겹쳐요.
- 불 끄는 장면(훈련, 출동 현장)은 실제 진압을 아주 단순하게 줄인 체험이고, 화면의 "알아 두기"에 그렇게 밝혀요. 구조 절차나 진압 전술을 정답처럼 가르치지 않아요.
- 돌아보기의 순간은 여덟 개예요. 교대 기록 읽기와 훈련 준비 순서 맞추기는 순간으로 세지 않아요.
- 무대가 지운 정도를 알아야 할 때는 `build()` 가 돌려주는 값에 `onRub(id, 0~1)` 을 적어요(불꽃이 작아지는 데 씀).
- 실제 소방관은 교대로 일하고 공무원 보수 규정에 따라 급여를 받아요. 여기서는 다른 직업과 같은 방법(커리어넷 평균 연봉 4,000만 원 → 시급 15,950원)으로 계산한 8시간 체험이고, 명세서에 그렇게 적어요.

화면 카드로 하는 장면도 있어요.

| 직업 | 장면 | 손으로 하는 일 |
|---|---|---|
| 약사 | 나가기 전에 한 번 더 | 처방전과 준비된 약 봉투를 한 칸씩 견주어 다른 곳 누르기 (약 이름은 가상) |
| 원무행정 직원 | 창구를 잠깐 비우기 전에 | 서류를 접수·수납·잠금 서류함에 끌어 넣고, 자리 비우기 전 화면 잠그기 |

- 무대는 `src/world/closeups.js` 에 이름 하나로 지어요. 문질러 지우는 얼룩(`patches`), 집어 옮기는 물건(`movers`), 여러 칸 중 맞는 칸에 넣는 자리(`slots`)를 적어요. 칸이 있으면 끄는 동안 빈 칸 모두에 같은 원이 떠서 정답이 드러나지 않아요.
- "닦고 제자리에 놓기" 장면은 `src/hands/tidy.js` 의 틀에 할 일, 순서, 실수 문구만 적으면 돼요.
- 장면에는 `closeup: true` 를 적어요. 폰에서는 이 장면 동안 3D 화면이 커져요.
- 3D가 안 되는 기기에서는 같은 일을 버튼으로 해요.

- 장면은 `kind: 'hands'`, `game`(놀이 이름), `grades`(결과 등급마다 `fx`, `flag`, `text`)로 적어요.
- 놀이는 결과를 등급 하나로 넘기고, 하루 엔진은 그 등급의 결과만 반영해요. 그래서 `npm test`가 모든 등급의 길을 끝까지 돌려 볼 수 있어요.
- 다른 직업에 넣으려면: `src/hands/`에 놀이를 하나 만들고 `index.js`에 더한 뒤, 직업 파일의 `before`·`after`·`order` 자리에 장면을 적어요.
- 진단이나 치료 판단은 가르치지 않아요. 손 위생, 환자 확인, 수술 복장, 봉합처럼 시중의 직업체험에도 나오는 손기술만 단순하게 그려요.

## 교사 기록 모으기 (`src/collect.js`, `shared/collect.js`)

서버 없이 모아요.

1. 학생: 첫 화면이나 퇴근 뒤 화면의 **선생님께 출근 기록 보내기** → 번호나 이름 적기 → **코드 만들기** → **복사하기** → 학급 게시판이나 메신저에 붙여 넣기
2. 교사: 첫 화면 맨 아래 **선생님용 · 출근 기록 모으기** → 받은 코드를 붙여 넣고 **더하기** → 표와 요약 보기, **CSV 내려받기**

- 번호나 이름은 코드를 만들 때만 쓰고 학생 기기에 남지 않아요. 모은 기록은 교사 기기에만 남아요.
- 같은 코드를 두 번 붙여 넣어도 한 번만 들어가요. 글자가 바뀐 코드는 알려 줘요.
- 한 잔의 하루(바리스타)의 코드도 같은 화면에서 받아요.

## 일당 계산 (`shared/workday.js`)

일당, 흥미 유형, 출근 기록은 다른 직업체험 앱(한 잔의 하루)과 함께 지키는 약속이라 저장소 맨 위 `shared/` 에 있어요. `src/pay.js` 는 그것을 다시 내보내기만 해요. 약속은 `shared/README.md` 를 보세요.


- 커리어넷 직업정보의 평균 연봉(중앙값, 만 원)을 씀 → `src/data/careernet.js`
- 시급 = 연봉 ÷ 12 ÷ 209시간, 기본급 = 시급 × 8시간
- 8시간을 넘겨 일하면 그 시간은 시급 × 1.5 (연장 근무 수당)
- 쉬는 시간에 일한 시간도 일한 시간으로 셈
- 자료로 계산한 시급이 올해 최저시급보다 낮으면(예: 청소원 2021년 자료) **최저시급**으로 계산하고, 명세서에 그 까닭을 밝힘
- 모두 세금·보험료를 떼기 전(세전). 직업당 표본이 적어 **직업끼리 순위를 매기지 않음**

자료를 새로 받으려면:

```bash
cd scripts && python3 fetch_careernet.py      # www.career.go.kr 접속 필요, 30분쯤
cd .. && python3 scripts/build_careernet.py scripts/jobs_raw.json
```

## 새 직업 더하기

1. `src/jobs/` 에 파일을 하나 만든다. 같은 일터의 직업이면 `nurse.js` 를 복사해서 고치는 게 가장 빨라요.
   - `careernet`: 커리어넷 직업 코드 (`src/data/careernet.js` 에서 이름으로 찾기)
   - `shift`: 출근·퇴근 시각, 쉬는 시간
   - 고민 넷(`first`, `team`, `incident` + 쉬는 시간은 틀에 있음), `order`, `pick`, `thanks`
   - 손으로 하는 장면을 넣으려면 `before: { first: [...] }`, `after: { order: [...] }`, 또는 `order` 자리에 `kind: 'hands'` (의사 파일 참고)
   - 커리어넷에 없는 직업은 가장 가까운 직업 코드를 쓰고 `careernetNote`로 밝히며, `works`(하는 일)를 직접 적는다
   - 장면 장소를 바꾸려면 `firstPlace`, `orderPlace`, `pickPlace` (예: 의사의 수술 장면은 `theatre`)
2. `src/jobs/index.js` 에 한 줄 더한다.
3. `npm test` — 아래가 하나라도 걸리면 실패해요.
   - 한 장면 안에서 다른 보기보다 **모든 면에서 못한 보기**(함정)
   - 한 번도 나오지 않는 고마움 말, 일어나지 않는 여파
   - 결말 이름과 게이지가 맞지 않음, 연장 근무 2시간 넘음, 시급이 최저임금보다 낮음
   - 목록(`index.js`)에 빠진 직업 파일

## 새 일터 더하기

`src/places/hospital.js` 나 `src/places/fire-station.js` 를 본떠 아래를 채우고 `src/places/index.js` 에 더해요.

- `rooms`(공간과 동료), `sets`(따로 보여 주는 방. `dress` 를 적으면 그 방에서 옷이 바뀜), `build`(바닥, 출입구)
- `icon`(그림 글자), `color`·`colorD`(일터 색, `shared/DESIGN.md` §1), `quiet`(기다리는 줄이 생기지 않는 곳)
- 하루의 틀은 `src/jobs/_hospital-day.js`, `src/jobs/_firestation-day.js` 처럼 일터마다 하나 만들어요. 하루의 순서는 모든 일터가 같아요(`shared/DESIGN.md` §4).
- 그 일터에서만 쓰는 3D 조각은 `src/world/firekit.js` 처럼 따로 모아, 일터 모형과 가까이 보기 무대가 함께 써요.
- 사이트 첫 화면(`workday-site/hub.html`)에 일터 카드와 도장 칸을 더하고 `node workday-site/build.mjs` 로 다시 묶어요.

## 지켜야 할 것

- 적성 판정이나 직업 순위를 내지 않아요. 돌아보기는 학생이 고른 순간에서 출발해요.
