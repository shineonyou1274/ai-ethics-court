# 오늘, 출근합니다 (career-day)

직업인의 하루를 직접 판단하며 살아 보고, 퇴근하면 그날의 일당을 받는 진로 체험 앱이에요.
빌드하면 `career-day.html` 한 파일이 나와서, 그 파일만 나눠 주면 돼요.

```bash
npm install
npm run dev     # 고치면서 보기
npm test        # 모든 직업의 모든 길을 끝까지 돌려 보는 검사
node ../shared/test.mjs   # 앱끼리 함께 지키는 약속 검사
npm run build   # career-day.html 만들기
```

## 들어 있는 일터와 직업

| 일터 | 직업 | 일터 색 |
|---|---|---|
| 🏥 모아 병원 (`hospital`) | 의사 · 간호사 · 임상병리사 · 방사선사 · 원무행정 직원 · 약사 · 물리치료사 · 환경미화 직원 | `#dc795e` |
| 🚒 다솜 소방서 (`fire-station`) | 소방관 (커리어넷 385) | `#d2553f` |

첫 화면에서 일터를 고르면 그 일터의 3D 모형과 직업 도장 카드가 나와요. 주소 끝에 `#fire-station` 처럼 일터 이름을 붙이면 그 일터부터 보여요.

## 하루의 구조

| 장면 | 하는 일 |
|---|---|
| 명찰 | 커리어넷의 "하는 일", 근무 시간, 시급 |
| 탈의실 | 근무복으로 갈아입기 (3D 캐릭터 옷이 바뀜) |
| 기록 | 카드를 눌러 오늘의 기록 펼치기 |
| 첫 만남 · 팀 · 쉬는 시간 · 돌발 | **결과가 이어지는 판단** (게이지 셋과 밀린 시간이 바뀜) |
| 순서 맞추기 | 일의 순서를 손으로 맞추기 (틀리면 시간이 듦) |
| 골라 담기 | 인계·확인할 것 고르기 (사실과 짐작, 개인정보) |
| 남은 한마디 | 앞선 선택에 따라 다른 말을 들음 |
| 퇴근 | 밀린 일이 있으면 남아서 마칠지(연장 수당) 넘길지 |
| 일당 명세서 → 퇴근길 돌아보기 | 끌린 순간·버거운 순간 → 흥미 유형 |

- 게이지: 🫶 안심(만나는 사람) · 🤝 호흡(동료) · 🔋 에너지(나)
- **밀린 시간**: 판단에 따라 일이 밀리면 시계가 늦어지고, 3D에 기다리는 줄이 생겨요.
- **여파(ripple)**: 앞의 선택이 뒤 장면에서 다시 나타나요. 예: 간호사가 "다시 오겠다"고 약속하고 일이 밀리면, 오후에 그 말을 다시 들어요.

### 소방관 (다솜 소방서) — 걸어 다니며 일이 찾아오는 하루 ("카페 방식", `shared/DESIGN.md` §2-3)

한 문장으로: **"나는 오늘 시장 점검을 하다 출동해 골목 불을 끄고, 약속한 세 시에 보람 님 가게에 들렀다(또는 못 들렀다)."**
소방서 안은 내 캐릭터로 걸어 다녀요. 바닥이나 3D의 장소 표시(📍 이름표와 노란 고리)를 누르거나, 아래 '○○로 걸어가기' 단추를 누르면 길을 찾아 걸어가고, 닿으면 그 장면이 열려요. 소방서 밖(시장, 학원 건물, 골목)은 걷지 않고 "소방차를 타고 가요" 한 장면으로 오가요.
일은 목록이 아니라 **찾아와요**. 아침 일정(교대 점검·시장 점검·훈련)은 처음부터 '받은 일'에 있고, 무전·출동 벨·팀장의 말로 새 일이 들어오며('새로 옴'), 시장에서 약속하면 "세 시, 보람 님 가게에 다시 들르기"가 목록에 올라 지키면 '마침', 지나치면 '못 함'이 돼요.

- 손으로 하는 3D 장면은 다섯이에요(교대 점검, 경보 확인, 방수 훈련, 골목 불 끄기, 다음 출동 준비). 시각은 밀린 시간만큼 늦어져요.
- 여파: 정비를 점심 뒤로 미루면 출동이 늦어지고, 먼저 해 두면 바로 나가요. 세 시 약속은 출동과 겹쳐서, 불을 끈 뒤 지키러 갈지 남은 일을 맡을지 골라야 해요.
- 돌아보기의 순간은 여덟 개예요. 손으로 하는 다섯 장면은 모두 순간으로 세요. 교대 기록 읽기, 훈련 준비 순서 맞추기, 출동 기록 고르기(손으로 한 "다음 출동 준비"가 그 자리를 맡아요)는 순간으로 세지 않아요(`type: null`).

#### 걸어 다니기를 다른 일터에 켜는 법 (`src/flow.js`, `src/world/nav.js`)

- 일터(`src/places/*.js`)에 `nav` 를 적어요: 걸을 수 있는 바닥 `bounds`, 막힌 곳 `blocks`(벽·가구), 걸어갈 자리 `spots`(이름 포함), 장면 자리 → 걸어갈 자리 `at`, 처음 자리 `start`, 일터 밖 `remote`(가는 말·돌아오는 말), 차를 타는 자리 `depart`, 걸을 때 보여 줄 화면 `frame`.
- 직업에 `walk: true` 를 적어요. 장면에는 `notice: { via, text }`(무전·출동 벨·전화처럼 찾아오는 알림)와 `todo`(받은 일 목록에 올릴 일. `known` 이면 아침 일정, 함수면 그 조건일 때만, `done`·`missed`·`at`)를 적어요.
- 둘 중 하나라도 없으면 지금처럼 장면이 차례로 열려요(간호사를 뺀 병원 직업 일곱). `npm test` 가 `test/walk.mjs` 로 모든 자리 사이의 길, 장면마다 걸어갈 길, 나간 만큼 돌아오는지, 찾아오는 일이 오기 전에 보이지 않는지, 약속이 조건대로 보이고 마치는지 확인해요.
- 실기 검사: `node career-day/test/e2e-fire.cjs <폴더> <iphone|se|pc> <clean|messy> [reduced]` 가 바닥 누르기·장소 표시 누르기·단추 세 가지로 번갈아 걸어가고, 손 장면은 실제로 끌어서 해요.

- 불 끄는 장면(훈련, 출동 현장)은 실제 진압을 아주 단순하게 줄인 체험이고, 화면의 "알아 두기"에 그렇게 밝혀요. 구조 절차나 진압 전술을 정답처럼 가르치지 않아요.
- 돌아보기의 순간은 여덟 개예요. 교대 기록 읽기와 훈련 준비 순서 맞추기는 순간으로 세지 않아요.
- **안전 한 줄**: "실제로 불이 나면 먼저 대피하고 119에 신고해요. 불을 끄는 건 훈련받은 소방관의 일이에요." 출동 벨 장면과 불 끄는 장면의 '알아 두기'에 그대로 넣어요(`src/jobs/firefighter.js` 의 `SAFETY`).
- 무대가 지운 정도를 알아야 할 때는 `build()` 가 돌려주는 값에 `onRub(id, 0~1, 점들)` 을 적어요. 물이 닿은 자리의 불꽃만 줄이는 데 써요.

### 간호사 (모아 병원 7층 병동) — 걸어 다니며 호출에 응하는 하루 ("카페 방식")

한 문장으로: **"병동을 돌며 호출에 응하고, 다온 님께 약속한 대로 다시 가 일정을 설명하고(또는 못 하고), 다음 근무자에게 인계했다."**
간호사만 병원 전체 모형이 아니라 **7층 병동** 한 층(`src/places/hospital-ward.js`)을 걸어 다녀요. 뒤쪽 줄에 병실 셋(701·702·703호)과 약품·물품실, 앞쪽 줄에 간호 스테이션·회의실·휴게실·탈의실이 있고 가운데가 복도예요. 직업 파일에 `floor: 'ward'` 를 적으면 `src/places/index.js` 의 `placeOf(job)` 가 그 층을 돌려줘요. 기록의 일터는 그대로 `hospital` 이에요.
**병원의 다른 일곱 직업은 바뀌지 않아요**: 병원 모형, 장면 차례, 걷지 않는 하루 그대로예요(`test/walk.mjs` 가 확인).
일은 **찾아와요**. 호출 벨·동료·의사·전화로 여섯 번 들어오고('새로 옴'), 아침에 "10시쯤 다시 와서 설명하겠다"고 약속하면 받은 일 목록에 올라 지키면 '마침', 지나치면 '못 함'이 돼요.

### 불과 물의 효과 (`src/world/fx.js`)

| 효과 | 모습 | 줄어드는 조건 |

| 소리 | 걸러 낸 잡음으로 '쏴아', 불에 닿으면 '치익' (`src/audio.js` 의 `spraySound`) | 소리 끄기(♪)를 따름. 무대를 떠나면 꺼짐 |
| 물안개와 김 | 닿는 곳에서 옅은 물안개가 피고, 불이 남은 곳이면 크고 짙은 흰 김이 됨 | 불이 꺼진 곳에서는 옅은 물안개만 |

- 입자 수는 `FX_MAX` 상수로 막아요(불티 16, 연기 9, 물살 48, 물보라 24, 물안개·김 10, 젖은 자국 26. 물줄기 토막은 심과 물안개 12개씩으로 고정). 미리 만들어 돌려 써요.
- 밝기는 무작위 값을 프레임마다 쓰지 않고 느린 물결 둘을 섞어 써요. 가장 빠른 물결도 1초에 한 번을 넘지 않아요.
- 기기 설정이 '동작 줄이기'면 흔들림·불티·튀는 물·김을 끄고, 물은 가만히 있는 굵은 한 줄로 보여 줘요. 불이 줄고 젖는 것은 그대로 보여요.
- 실제 소방관은 교대로 일하고 공무원 보수 규정에 따라 급여를 받아요. 여기서는 다른 직업과 같은 방법(커리어넷 평균 연봉 4,000만 원 → 시급 15,950원)으로 계산한 8시간 체험이고, 명세서에 그렇게 적어요.

화면 카드로 하는 장면도 있어요.

| 직업 | 장면 | 손으로 하는 일 |
|---|---|---|
| 약사 | 나가기 전에 한 번 더 | 처방전과 준비된 약 봉투를 한 칸씩 견주어 다른 곳 누르기 (약 이름은 가상) |

- 무대는 `src/world/closeups.js` 에 이름 하나로 지어요. 문질러 지우는 얼룩(`patches`), 집어 옮기는 물건(`movers`), 여러 칸 중 맞는 칸에 넣는 자리(`slots`)를 적어요. 칸이 있으면 끄는 동안 빈 칸 모두에 같은 원이 떠서 정답이 드러나지 않아요.
- "닦고 제자리에 놓기" 장면은 `src/hands/tidy.js` 의 틀에 할 일, 순서, 실수 문구만 적으면 돼요.
- 장면에는 `closeup: true` 를 적어요. 폰에서는 이 장면 동안 3D 화면이 커져요.
- 3D가 안 되는 기기에서는 같은 일을 버튼으로 해요.
- 3D 무대는 칸에 꽉 차게 맞춰요(`src/world/world.js` 의 `fit`). 가로는 무대 폭에, 세로는 위쪽 띠 아래부터 칸 바닥까지에 맞추고, 칸이 세로로 길면(폰) 카메라가 더 위에서 내려다봐요. 무대 크기가 기본(가로 5.8 × 깊이 4.2)과 다르면 `build()` 가 `frame: { w, d, top }` 을 돌려줘요.
- 폰에서는 할 일 목록을 접어 지금 할 일 하나만 크게 보여 주고(`src/hands/closeup-ui.js`), 장면 설명은 "상황 다시 보기"로 접어요. PC에서는 처음부터 펼쳐 둬요. 폰의 가까이 보기 동안에는 소리 버튼을 위쪽 띠 아래로 올려요(아래까지 찬 3D의 물건을 가리지 않게).
- 무대가 다른 곳으로 바뀔 때(가까이 보기에서 나올 때, 따로 지은 방과 일터 사이)는 카메라를 바로 옮기고 그 자리에서 한 번 그려요. 미끄러지게 두면 두 곳 사이의 빈 곳이 잠깐 보여요. 같은 일터 안에서 방을 옮길 때만 부드럽게 움직여요.

- 장면은 `kind: 'hands'`, `game`(놀이 이름), `grades`(결과 등급마다 `fx`, `flag`, `text`)로 적어요.
- 놀이는 결과를 등급 하나로 넘기고, 하루 엔진은 그 등급의 결과만 반영해요. 그래서 `npm test`가 모든 등급의 길을 끝까지 돌려 볼 수 있어요.
- 다른 직업에 넣으려면: `src/hands/`에 놀이를 하나 만들고 `index.js`에 더한 뒤, 직업 파일의 `before`·`after`·`order` 자리에 장면을 적어요.
- 진단이나 치료 판단은 가르치지 않아요. 손 위생, 환자 확인, 수술 복장, 봉합처럼 시중의 직업체험에도 나오는 손기술만 단순하게 그려요.

## 교사 기록 모으기 (`src/collect.js`, `shared/collect.js`)

서버 없이 모아요.

1. 학생: 첫 화면이나 퇴근 뒤 화면의 **선생님께 출근 기록 보내기** → 번호나 이름 적기 → **코드 만들기** → **복사하기** → 학급 게시판이나 메신저에 붙여 넣기
2. 교사: 첫 화면 맨 아래 **선생님용 · 출근 기록 모으기** → 받은 코드를 붙여 넣고 **더하기** → 표와 요약 보기, **CSV 내려받기**

- 같은 코드를 두 번 붙여 넣어도 한 번만 들어가요. 글자가 바뀐 코드는 알려 줘요.
- 한 잔의 하루(바리스타)의 코드도 같은 화면에서 받아요.

## 일당 계산 (`shared/workday.js`)

일당, 흥미 유형, 출근 기록은 다른 직업체험 앱(한 잔의 하루)과 함께 지키는 약속이라 저장소 맨 위 `shared/` 에 있어요. `src/pay.js` 는 그것을 다시 내보내기만 해요. 약속은 `shared/README.md` 를 보세요.


- 커리어넷 직업정보의 평균 연봉(중앙값, 만 원)을 씀 → `src/data/careernet.js`
- 시급 = 연봉 ÷ 12 ÷ 209시간, 기본급 = 시급 × 8시간
- 8시간을 넘겨 일하면 그 시간은 시급 × 1.5 (연장 근무 수당)
- 쉬는 시간에 일한 시간도 일한 시간으로 셈
- 자료로 계산한 시급이 올해 최저시급보다 낮으면(예: 청소원 2021년 자료) **최저시급**으로 계산하고, 명세서에 그 까닭을 밝힘
- 모두 세금·보험료를 떼기 전(세전). 직업당 표본이 적어 **직업끼리 순위를 매기지 않음**

자료를 새로 받으려면:

```bash
cd scripts && python3 fetch_careernet.py      # www.career.go.kr 접속 필요, 30분쯤
cd .. && python3 scripts/build_careernet.py scripts/jobs_raw.json
```

- 적성 판정이나 직업 순위를 내지 않아요. 돌아보기는 학생이 고른 순간에서 출발해요.
