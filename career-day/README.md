# 오늘, 출근합니다 (career-day)

직업인의 하루를 직접 판단하며 살아 보고, 퇴근하면 그날의 일당을 받는 진로 체험 앱이에요.
빌드하면 `career-day.html` 한 파일이 나와서, 그 파일만 나눠 주면 돼요.

```bash
npm install
npm run dev     # 고치면서 보기
npm test        # 모든 직업의 모든 길을 끝까지 돌려 보는 검사
node ../shared/test.mjs   # 앱끼리 함께 지키는 약속 검사
npm run build   # career-day.html 만들기
```

## 들어 있는 직업 (모아 병원)

의사 · 간호사 · 임상병리사 · 방사선사 · 원무행정 직원 · 약사 · 물리치료사 · 환경미화 직원

## 하루의 구조

| 장면 | 하는 일 |
|---|---|
| 명찰 | 커리어넷의 "하는 일", 근무 시간, 시급 |
| 탈의실 | 근무복으로 갈아입기 (3D 캐릭터 옷이 바뀜) |
| 기록 | 카드를 눌러 오늘의 기록 펼치기 |
| 첫 만남 · 팀 · 쉬는 시간 · 돌발 | **결과가 이어지는 판단** (게이지 셋과 밀린 시간이 바뀜) |
| 순서 맞추기 | 일의 순서를 손으로 맞추기 (틀리면 시간이 듦) |
| 골라 담기 | 인계·확인할 것 고르기 (사실과 짐작, 개인정보) |
| 남은 한마디 | 앞선 선택에 따라 다른 말을 들음 |
| 퇴근 | 밀린 일이 있으면 남아서 마칠지(연장 수당) 넘길지 |
| 일당 명세서 → 퇴근길 돌아보기 | 끌린 순간·버거운 순간 → 흥미 유형 |

- 게이지: 🫶 안심(만나는 사람) · 🤝 호흡(동료) · 🔋 에너지(나)
- **밀린 시간**: 판단에 따라 일이 밀리면 시계가 늦어지고, 3D에 기다리는 줄이 생겨요.
- **여파(ripple)**: 앞의 선택이 뒤 장면에서 다시 나타나요. 예: 간호사가 "다시 오겠다"고 약속하고 일이 밀리면, 오후에 그 말을 다시 들어요.

## 손으로 하는 장면 (`src/hands/`)

판단만 고르는 게 아니라 손으로 직접 해 보는 장면이에요. 지금은 **의사**(넷), **환경미화 직원**, **간호사**에 들어 있어요.

### 의사 시험판

| 시각 | 장면 | 손으로 하는 일 | 결과가 이어지는 곳 |
|---|---|---|---|
| 08:12 | 손 위생 | 손 그림 위의 균을 여섯 단계로 문질러 지우기. 중간에 서둘러 나갈 수 있음 | 서두르면 병실 앞에서 손 소독을 한 번 더 함 |
| 08:18 | 환자 확인 | 침대 셋 가운데 팔찌를 읽어 이름과 생년월일이 모두 맞는 분 찾기 (이름이 같은 분, 생년월일이 같은 분이 섞여 있음) | 잘못 짚으면 다시 확인하느라 시간이 듦 |
| 09:10 | 수술 준비 | 모자·마스크 → 손 세척 → 가운 → 장갑을 끌어다 입기, 팀과 타임아웃 | 순서가 엇갈리면 팀이 기다림 |
| 09:55 | 봉합 | 위 점에서 아래 점까지 끌어 다섯 땀 꿰매기 | 많이 놓치면 다시 꿰매느라 시간과 힘이 듦 |

### 3D 일터에서 직접 닦고 옮기기 (`src/world/closeup.js`)

바리스타의 테이블 닦기처럼, 3D 화면이 일터 가까이 내려가고 학생이 3D 위를 손가락으로 직접 문지르거나 물건을 집어 옮겨요.

| 직업 | 장면 | 손으로 하는 일 | 판단이 갈리는 곳 |
|---|---|---|---|
| 환경미화 직원 | 로비 바닥이 젖었어요 | 노란 안내판을 끌어 세우고, 대걸레로 물웅덩이와 물자국을 문질러 닦기 | 안내판 없이 닦기 시작하면 지나가던 분이 미끄러질 뻔함 |
| 간호사 | 퇴원한 자리를 다음 분을 위해 | 쓴 시트를 세탁함에 끌어 넣고, 매트리스를 소독 티슈로 문지르고, 새 시트를 끌어 깔기 | 소독 전에 새 시트를 깔려 하면 막히고 시간이 듦 |

- 무대는 `src/world/closeups.js` 에 이름 하나로 지어요. 문질러 지우는 얼룩(`patches`)과 집어 옮기는 물건(`movers`)만 적으면 돼요.
- 장면에는 `closeup: true` 를 적어요. 폰에서는 이 장면 동안 3D 화면이 커져요.
- 3D가 안 되는 기기에서는 같은 일을 버튼으로 해요.

- 장면은 `kind: 'hands'`, `game`(놀이 이름), `grades`(결과 등급마다 `fx`, `flag`, `text`)로 적어요.
- 놀이는 결과를 등급 하나로 넘기고, 하루 엔진은 그 등급의 결과만 반영해요. 그래서 `npm test`가 모든 등급의 길을 끝까지 돌려 볼 수 있어요.
- 다른 직업에 넣으려면: `src/hands/`에 놀이를 하나 만들고 `index.js`에 더한 뒤, 직업 파일의 `before`·`after`·`order` 자리에 장면을 적어요.
- 진단이나 치료 판단은 가르치지 않아요. 손 위생, 환자 확인, 수술 복장, 봉합처럼 시중의 직업체험에도 나오는 손기술만 단순하게 그려요.

## 일당 계산 (`shared/workday.js`)

일당, 흥미 유형, 출근 기록은 다른 직업체험 앱(한 잔의 하루)과 함께 지키는 약속이라 저장소 맨 위 `shared/` 에 있어요. `src/pay.js` 는 그것을 다시 내보내기만 해요. 약속은 `shared/README.md` 를 보세요.


- 커리어넷 직업정보의 평균 연봉(중앙값, 만 원)을 씀 → `src/data/careernet.js`
- 시급 = 연봉 ÷ 12 ÷ 209시간, 기본급 = 시급 × 8시간
- 8시간을 넘겨 일하면 그 시간은 시급 × 1.5 (연장 근무 수당)
- 쉬는 시간에 일한 시간도 일한 시간으로 셈
- 자료로 계산한 시급이 올해 최저시급보다 낮으면(예: 청소원 2021년 자료) **최저시급**으로 계산하고, 명세서에 그 까닭을 밝힘
- 모두 세금·보험료를 떼기 전(세전). 직업당 표본이 적어 **직업끼리 순위를 매기지 않음**

자료를 새로 받으려면:

```bash
cd scripts && python3 fetch_careernet.py      # www.career.go.kr 접속 필요, 30분쯤
cd .. && python3 scripts/build_careernet.py scripts/jobs_raw.json
```

## 새 직업 더하기

1. `src/jobs/` 에 파일을 하나 만든다. 같은 일터의 직업이면 `nurse.js` 를 복사해서 고치는 게 가장 빨라요.
   - `careernet`: 커리어넷 직업 코드 (`src/data/careernet.js` 에서 이름으로 찾기)
   - `shift`: 출근·퇴근 시각, 쉬는 시간
   - 고민 넷(`first`, `team`, `incident` + 쉬는 시간은 틀에 있음), `order`, `pick`, `thanks`
   - 손으로 하는 장면을 넣으려면 `before: { first: [...] }`, `after: { order: [...] }`, 또는 `order` 자리에 `kind: 'hands'` (의사 파일 참고)
   - 커리어넷에 없는 직업은 가장 가까운 직업 코드를 쓰고 `careernetNote`로 밝히며, `works`(하는 일)를 직접 적는다
   - 장면 장소를 바꾸려면 `firstPlace`, `orderPlace`, `pickPlace` (예: 의사의 수술 장면은 `theatre`)
2. `src/jobs/index.js` 에 한 줄 더한다.
3. `npm test` — 아래가 하나라도 걸리면 실패해요.
   - 한 장면 안에서 다른 보기보다 **모든 면에서 못한 보기**(함정)
   - 한 번도 나오지 않는 고마움 말, 일어나지 않는 여파
   - 결말 이름과 게이지가 맞지 않음, 연장 근무 2시간 넘음, 시급이 최저임금보다 낮음
   - 목록(`index.js`)에 빠진 직업 파일

## 새 일터 더하기

`src/places/hospital.js` 를 본떠 `rooms`(공간과 동료), `sets`(따로 보여 주는 방), `build`(바닥, 출입구)를 채우고
`src/places/index.js` 에 더해요. 하루의 틀은 `src/jobs/_hospital-day.js` 처럼 일터마다 하나 만들면 돼요.

## 지켜야 할 것

- 적성 판정이나 직업 순위를 내지 않아요. 돌아보기는 학생이 고른 순간에서 출발해요.
- 의료 등 전문 업무를 정답처럼 가르치지 않아요. 판단은 시간, 소통, 팀과의 조율에 관한 것만 다뤄요.
- 등장인물과 기록은 모두 가상이에요.
- 3D 일터는 「어쩌다 병원」의 모형을 옮겨 왔어요.
