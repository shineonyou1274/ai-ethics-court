# 복원 범위와 검증

기준: 통합 `4d9a014`. 비교 대상: 11/16 `815264e`. 작업 브랜치: `codex/barista-restore`.

## 복원

- 장소 표시, 손 장면 제목·도입·하단 조작 안내를 되살렸습니다.
- 위쪽 띠를 3D 위에, 위치·토스트를 원래 자리에 돌렸습니다.
- 명찰의 시작 버튼·다른 일터 링크·지갑을 예전 배치로 돌렸습니다.
- 뒤에 추가한 일괄 글자 확대, 설명 접기, 고정 행동 버튼 칸을 제거했습니다.

## 유지한 버그 수정

- 컵 확대창은 우유 버튼을 덮지 않습니다. 작은 SE에서는 확대창을 왼쪽으로 두고 우유·오트밀크 버튼을 위아래로 나눴습니다.
- 수도 버튼은 진녹색 배경과 흰 글자입니다.
- 두 번째 손님 뒤 휴식, `break` 이름, 휴식 중 행동 차단을 유지했습니다.
- 첫 시도 컵 잡기 판정, 씻은 컵 재사용, 결제·영수증 로직은 그대로입니다.
- PAY_NOTE, 항상 보이는 최저시급 비교, `.wd-moment`, 동작 줄이기를 유지했습니다.
- 일부 9~10px 꼬리표만 14px로 바꿨습니다. 제조대 표시 폭과 SE 선반·건조대 표시 위치만 화면 안으로 보정했습니다.

새로 감춘 정보는 없습니다. `body.onBreak`에서 행동·버리기 버튼을 감추는 규칙은 기존 휴식 수정의 유지이며, 쉬는 동안 작업을 진행하지 않도록 합니다. 그 외 원래 판의 장면별 표시 전환은 그대로입니다.

## 재현

Playwright가 설치된 환경에서 `/old/barista-day/`는 `815264e:barista-day/dist`, `/new/`는 현 소스의 `workday-site/public`을 가리키도록 로컬 HTTP 서버 8123을 띄웁니다.

```
VERSION=old node barista-day/tests/restore-day.cjs <old-final 출력 폴더>
VERSION=new VIDEO=1 node barista-day/tests/restore-day.cjs <new-final 출력 폴더>
node barista-day/tests/restore-layout.cjs <레이아웃 출력 폴더>
node barista-day/tests/compare-gallery.cjs <두 출력 폴더의 부모> <비교 폴더>
node shared/tools/flicker.cjs <녹화.webm>
```

하루 검사는 테스트 응답에만 읽기용 상태를 노출해 대기·3D 좌표 투영에 씁니다. 상태를 강제로 진행하지 않고 실제 클릭·누르기·끌기로 세 손님, 결제·영수증, 제조, 테이블 닦기, 컵 씻기·선반 정리·재사용, 휴식, 마감과 기록 저장을 수행합니다. 레이아웃 검사는 별도로 중간 상태를 주입하며 전체 하루 검사와 구분합니다.

## 비교 관찰

7쌍 이미지를 시각적으로 검토했습니다. 실제 휴대전화 하드웨어가 아니라 Chromium의 390×844 뷰포트·터치 지원 환경에서 촬영했습니다. 명찰은 같은 배치이며, 손님 맞이의 위쪽 띠·위치 안내가 복원됐습니다. 계산·세척·테이블의 장소 표시와 제목이 보입니다. 제조대는 예전의 컵 확대창 겹침과 흰 안내 글자를 개선했습니다. 명세서는 보존한 PAY_NOTE·최저시급 설명 때문에 길어졌으며 내용을 숨기지 않고 스크롤로 볼 수 있습니다.

독립 채점자의 A15 시각 비교와 A16 한 문장 평가는 총괄 재검토가 필요합니다. 개발자가 이야기를 미리 알려 준 뒤의 응답을 A16 통과로 세지 않습니다. 전체 PC 하루·동작 줄이기 하루·0.2초 프레임 전수 검토를 이번 표적 검사로 대신하지 않습니다.

운영 배포와 PR 병합은 하지 않았습니다. 우주항공 소스는 변경하지 않았습니다.

## 현재 검사 결과

- 공통 약속, 병원·소방관 시뮬레이션, 바리스타·우주항공 `.mjs` 회귀 검사, 사이트 묶음 일치 검사 통과.
- SE 320×568 / iPhone 13 390×844 / PC 1280×800 표적 배치 검사 통과. 이 표적 검사는 동작 줄이기 설정으로 실행했습니다.
- 427.7초 복원 판 하루 녹화: `maxFlashesPerSec: 1`, `whiteFrames: 0`, `pass: true`. 원본은 로컬 `outputs/cafe-restore/new-final/`에 보관했습니다.
- 초기 반복 횟수 180 제한으로 하루 검사가 조기에 끝나 400으로 늘렸습니다. 또한 작은 폰의 우유 버튼·컵 확대창 겹침, 우유·오트 버튼 겹침, 건조대 글자 잘림을 표적 검사에서 발견하고 수정한 뒤 세 화면 크기를 다시 통과했습니다.
- `grading-six.cjs`의 일괄 16px·고정 행동 칸 조건은 이번 복원 요청과 충돌하는 예전 기준입니다. 이번 화면 판정은 `restore-layout.cjs`와 전후 비교를 사용하며, 옛 숫자 조건을 통과했다고 표시하지 않습니다.

최종 결과: 예전·복원 판 모두 390×844 전체 하루 종료, 손님 기록 3개, 같은 컵 3회 사용, 가로 밀림 0, pageerror/콘솔 오류 0, 출근 기록 저장 확인. `old-result.json`, `new-result.json`을 함께 보관합니다. 앞선 녹화 실행은 기록 저장 화면까지 도달했지만 완료 JSON이 남지 않아, 최종 실행으로 다시 확인했습니다. 해당 녹화의 A5/A6 결과와 최종 실행의 기능 결과는 구분합니다.
