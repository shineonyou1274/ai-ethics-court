# 카페와 박물관의 손 장면 비교

같은 390×844 화면으로 비교했다. 각 사진은 왼쪽부터 저장소의 바리스타 조작 사진, 학예사 채점판(ec0cd9b), 수정판의 작업 시작, 수정판의 작업 완료 순서다. 네 번째 칸은 물건을 놓거나 손을 뗀 뒤의 모습이다.

- [질그릇 옮기기](carry.jpg) · 카페에서 컵을 옮길 때와 질그릇을 두 손으로 받쳐 완충 상자에 놓을 때
- [흙 털기](brush.jpg) · 컵을 문지를 때와 붓으로 질그릇의 흙을 걷어 낼 때. [붓질 도중의 무늬와 진행률](../phone/brush-progress.png)
- [뚜껑 조각 맞추기](fit.jpg) · 돈을 집어 놓을 때와 조각을 돌려 받침에 끼울 때
- [진열장 조절](case.jpg) · 수도를 조작할 때와 경보를 확인하고 전시 환경 손잡이를 돌릴 때
