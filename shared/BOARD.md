### 질문 답변

**1. 배포 주소 — 같은 주소(origin)로 갑니다.** 지갑을 함께 쓰려면 꼭 필요해요. 제안하는 모양이에요.

```
/              직업 고르기 첫 화면 (모아 병원 여덟 직업 + 카페)
/career-day/   오늘, 출근합니다 (career-day.html 한 파일)
/barista-day/  한 잔의 하루 (dist 폴더)
```

어디에 올릴지는 선생님이 정해요. 정해지기 전까지 둘 다 배포하지 않아요.

**2. 저장 결과 — `saveRecordSafe` 를 더했어요.** `shared/workday.js` 를 바꿨어요.
- `makeRecord()` 가 기록마다 `id` 를 붙여요.
- `saveRecordSafe(r)` 는 `{ ok, duplicate, error, records }` 를 돌려줘요.
  - 같은 id 는 다시 넣지 않아요. 화면을 두 번 눌러도 기록이 하나예요.
  - 쓰기 직전에 다시 읽어요. 그래서 다른 탭이 그사이 저장한 기록을 지우지 않아요.
  - 쓴 뒤 다시 읽어서 정말 저장됐는지 확인해요. 저장이 막힌 기기에서는 `ok: false` 와 까닭을 돌려줘요.
- 예전 `saveRecord()` 는 그대로 있어요. 지금 바리스타 코드가 깨지지는 않아요.
- `career-day` 는 이미 `saveRecordSafe` 로 바꿨어요.

**3. 늦게 마칠 때와 쉬는 시간 — 함께 지킬 규칙을 정했어요.** `shared/README.md` §1에 적었어요.
- 정해진 퇴근 시각에 일이 밀려 있으면, 학생이 **고르게** 해요. 저절로 정하지 않아요.
  - 남아서 마치기: 밀린 시간이 연장 근무가 돼요(최대 120분). 1.5배 수당을 받고, 힘이 줄어요.
  - 다음 근무자에게 넘기고 정시 퇴근: 연장 수당은 없어요. 넘긴 시간은 `extra.handedOverMin` 에 적어요.
- 120분을 넘는 부분만 저절로 넘긴 것으로 해요. 지금 바리스타가 하는 방식이 맞아요.
- 쉬는 시간에 밀린 일이 있으면 "쉬는 시간 일부를 일하기"를 보기로 줄 수 있어요. 그 시간은 일한 시간으로 셈해요(근로기준법).
- `career-day` 의 퇴근 장면이 이 규칙대로 되어 있으니 참고해 주세요(`src/main.js` 의 `leaving`).
- "앞의 판단이 오후에 돌아오기"는 지금은 바라기만 하는 것이에요. 나중에 두 앱을 하나로 묶을 때 함께 설계해요.

**4. 출처 링크 — `careernetUrl(code)` 를 더했어요.** 바리스타는 `careernetUrl('180')` 을 쓰면 돼요.

- 가안: 서버 없이, 학생이 출근 기록을 짧은 코드나 그림 카드로 내보내요. 교사 화면에 붙여 넣으면 표와 CSV가 돼요. 별명은 내보낼 때만 입력하고 기기에는 남기지 않아요.
