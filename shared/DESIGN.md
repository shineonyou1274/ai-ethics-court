# 직업체험 앱 디자인 약속 (v1 · 2026-11-15)

일터는 달라도 **한 시리즈**로 느껴지게 하는 약속이에요. 새 일터(예: 소방서)를 만들 때도 이 문서와 `shared/README.md` 를 먼저 읽어요.
색과 글꼴, 공통 부품은 `shared/design.css` 에 코드로 있어요. 앱에는 그대로 복사해서 쓰고, 고칠 때는 `shared/` 에서만 고쳐요.

## 0. 원칙

- **틀은 같고, 일터는 달라요.** 학생이 일터를 옮겨도 화면 읽는 법과 조작법을 새로 배우지 않게 해요.
- 일터마다 다른 것은 세 가지뿐이에요: **강조색 하나**, **3D 일터 모습**, **그 일터에서 손으로 하는 일**.
- 긴 설명을 넘기며 읽는 게임으로 만들지 않아요. 직접 해 보고, 결과를 보고, 짧게 알려 줘요.

## 2. 화면 배치

- **폰(세로)**: 위 3D, 아래 할 일 칸. 손으로 하는 장면에서는 3D를 크게(56dvh) 키워요.
- **PC(가로)**: 왼쪽 3D, 오른쪽 할 일 칸(너비 40%, 최소 400px).
- 좌우 여백 16px. 가로로 밀리는 화면이 없게 해요.
- 3D가 안 되는 기기에서는 같은 일을 버튼과 문지르기로 끝까지 할 수 있어야 해요.

### 2-1. 폰에서 답답하지 않게 (2026-11-17 선생님 결정)

- **3D는 칸을 꽉 채워요.** 일터나 가까이 보기 무대가 칸 위쪽에만 그려지고 아래가 비지 않게 카메라를 맞춰요.
- **손으로 하는 장면에서는 할 일 목록을 접어요.** 지금 할 일 하나만 이름과 %를 크게 보이고, 나머지는 동그라미(마친 것은 초록)로만 보여요. 누르면 펼쳐져요. 장면 설명 문단은 "상황 다시 보기"로 접어요.
- **글자를 줄여서 해결하지 않아요.** 본문 16px 이상을 지켜요.
- **3D 위에 글을 띄우지 않아요.** 위쪽 띠(일당)와 학생이 끌어야 할 물건을 가리기 때문이에요. 짧은 말풍선(동료 한마디)만 예외예요.
- 폰 세로에서 아래 칸 안을 스크롤해야 할 일 버튼이 보이는 일이 없게 해요.

## 3. 화면 위쪽 띠 (HUD) — 모든 앱 같은 자리, 같은 모양

왼쪽부터 순서대로 놓아요.

1. **직업 이름 · 시각** (짙은 알약 `.wd-clock`). 일이 밀리면 옆에 "12분 밀림".
2. (있으면) 게이지 또는 그 일터의 상태 표시. 세 개 이하.
3. **🪙 오늘 번 일당** (`.wd-money`). 일한 시간만큼 늘어나요.

- 위쪽 띠에 **가게 매출이나 손님이 낸 돈을 두지 않아요.** 학생이 받는 돈은 일당이에요. 매출은 퇴근 화면의 "가게 기록"에서만 보여요.
- 오른쪽 아래 둥근 버튼: 소리(♪), (폰) 3D 크게 보기. 도움말(?)은 있어도 돼요.

## 4. 하루의 순서 — 모든 앱 같음

```
첫 화면(일터 고르기) → 명찰(하는 일, 근무 시간, 시급) → 탈의·준비 → 일하기(판단 + 손으로 하는 일)
→ 쉬는 시간 → 일하기 → [늦게 마치면] 남기·넘기기 고르기 → 일당 명세서 → 퇴근길 돌아보기 → 출근 기록 남기기
```

- **명찰**: 커리어넷의 하는 일 세 줄, 근무 시간과 쉬는 시간, 시급과 8시간 일당.
- **일당 명세서**: 한 장으로, 이 순서를 지켜요.
  1. 큰 숫자: 오늘 번 일당(세전)
  1-1. 그 바로 아래, 접지 않고 늘 보이게: `PAY_NOTE` 한 줄 (`shared/workday.js`) — "일당은 오늘 한 일의 양이 아니라, 그 직업 사람들의 평균 연봉에서 나와요…"
  2. 표: 기본급(시급 × 시간), 연장 근무 수당(있을 때만), 쉬는 시간에 일한 시간(있을 때만)
  3. "이 일당은 어떻게 나왔을까?": 자료 출처 링크, 기준 해, 최저 시급과 견주기
  4. (있으면) 접힌 "가게 기록": 매출, 재료비, 손님 반응
- **퇴근길 돌아보기**: 퇴근길 한 줄(하루에 따라 달라짐) → 순간 카드 → 💛 끌린 순간 하나, 🪨 버거운 순간 하나 → 흥미 유형 설명 → "순간 하나로 나를 정할 수는 없어요" 안내 → 기록 남기기.
  - 순간은 **누르는 카드**(`.wd-moment`)로 보여 줘요. 펼침 목록을 쓰지 않아요.
- **출근 기록을 남긴 뒤**: 같은 직업 다시 하기 · 다른 일터 고르기(`../`) · 선생님께 출근 기록 보내기.

## 5. 손으로 하는 일 — 손맛을 같게

| 동작 | 약속 |
|---|---|
| **문지르기** | 손가락이 지나간 길의 얼룩만 지워져요. 도구(걸레, 티슈, 수세미)가 손가락을 따라와요. 진행률을 %로 보여 줘요. |
| **끌어 놓기** | 누르면 물건이 살짝 들려요. 놓을 자리에 초록 원이 떠요. 여러 칸 중 맞는 칸을 고르는 일이면 **빈 칸 모두에 같은 원**을 띄워 정답이 드러나지 않게 해요. 틀린 칸이면 제자리로 돌아오고 까닭을 한 줄로 알려 줘요. |
| **누르기** | 누를 것은 들썩이거나 반짝여서 눈에 띄게 해요. |
| **순서** | 순서가 중요한 일은 먼저 하려 할 때 막고, 왜 먼저 해야 하는지 한 줄로 알려 줘요. |

- 실수는 벌이 아니라 **시간**으로 돌아와요("5분 밀림"). 꼼꼼하게 하면 시간이 들고, 서두르면 뒤에서 다시 돌아오게 해요.
- 할 일 목록은 동그라미 체크(`.todo` 모양)로 보여 주고, 마친 것은 초록으로 바꿔요.

## 6. 말투

- 학생에게 **해요체**로, 짧게. 한 줄에 한 가지.
- 판정하지 않아요. "잘했어요/못했어요" 대신 무엇이 어떻게 됐는지 알려 줘요. 예: "튜브를 다시 확인해 꽂았어요. 검사가 조금 늦게 시작해요."
- 전문 업무를 정답처럼 가르치지 않아요. 단순하게 만든 것은 "단순화한 체험"이라고 밝혀요.
- 등장인물은 가상 이름. 실제 기관·상표를 쓰지 않아요.
