# 완성 체크리스트 (검증 조건)

> 일을 "끝났다"고 하기 전에 이 목록을 모두 통과해야 해요. Claude(총괄)가 채점 에이전트로 다시 확인해요.
> 각 항목은 **통과 / 실패 / 해당 없음** 중 하나이고, 실패에는 반드시 **증거**(명령 출력, 스크린샷 경로, 파일:줄)를 붙여요.
> 점수는 쓰지 않아요. **필수(●) 항목이 하나라도 실패면 "미완성"** 이에요. 권장(○)은 실패해도 완성이지만 다음 일로 남겨요.

## A. 모든 일터 공통

| 번호 | 항목 | 통과 조건 (어떻게 확인하나) |
|---|---|---|
| A1 ● | 검사 통과 | `node shared/test.mjs`, `(cd career-day && npm test)`, `barista-day/tests/*.mjs`, `aerospace-day/tests/*.mjs` 모두 종료 코드 0 |
| A2 ● | 사이트 묶음 | `node workday-site/build.mjs` 뒤 `--check` 가 "소스와 같아요" |
| A3 ● | 오류 없음 | 폰(iPhone 13)과 PC(1280×800)에서 첫 화면 → 일터 → 하루 끝까지 진행하는 동안 `pageerror`·콘솔 오류·4xx/5xx 응답 0개 |
| A4 ● | 가로 밀림 없음 | 모든 장면에서 `document.documentElement.scrollWidth - innerWidth <= 0` |
| A5 ● | **빛 번쩍임** | 영상 녹화 후 `node shared/tools/flicker.cjs <영상>` → `maxFlashesPerSec <= 3` (화면 전체와 4×4 칸 모두). 불·경광등·사진 플래시처럼 밝기가 변하는 장면은 반드시 녹화 |
| A6 ● | **흰 화면 없음** | 같은 검사에서 `whiteFrames == 0`. 장면을 넘길 때, 3D를 처음 띄울 때, 가까이 보기를 열고 닫을 때를 꼭 포함 |
| A7 ● | 카메라 점프 없음 | 장면 전환 녹화를 0.2초 간격 프레임으로 넘겨 보며, 카메라가 한 프레임 만에 다른 곳으로 순간 이동한 뒤 다시 돌아오는 일이 없음(의도한 컷 전환 한 번은 괜찮음) |
| A8 ● | 겹친 면 지글거림 없음 | 바닥 위 얼룩·그을음·물웅덩이·표시선이 바닥과 같은 높이에 있지 않음(코드에서 y 띄움 ≥ 0.005 또는 `polygonOffset`), 카메라가 움직이는 녹화에서 무늬가 깜박이지 않음 |
| A9 ● | 아래 칸 번쩍임 없음 | 할 일 칸을 다시 그릴 때 빈 칸이 한 프레임 보이지 않음(A6 검사에 포함), 버튼 누를 때 칸 전체가 깜박이지 않음 |
| A10 ● | 동작 줄이기 | `reducedMotion: 'reduce'` 로 열면 입자·흔들림·번쩍임이 줄거나 멈추고, 그래도 끝까지 할 수 있음 |
| A11 ● | 디자인 약속 | `shared/DESIGN.md` §7 체크 목록 모두 (위쪽 띠에 매출 없음, 하루 순서, 명세서 순서, 누르는 순간 카드, 실수는 시간으로, `makeRecord → checkRecord → saveRecordSafe`, 다른 일터 고르기 길, 3D 없는 기기) |
| A12 ● | 진로 원칙 | 적성 판정·직업 순위 없음, 전문 업무를 정답처럼 가르치지 않음(단순화했다고 밝힘), 등장인물·기관 가상 |
| A14 ● | **숨겨서 통과하지 않기** | 고친 판에서 장소 표시·장면 제목·안내·되돌아가는 길이 사라지지 않았음. `display:none`·`hidden` 으로 새로 감춘 것은 하나씩 까닭을 적음 |
| A15 ● | **전과 후 나란히** | 고치기 전 판과 고친 판으로 같은 하루를 돌려, 같은 장면(명찰·일하기·손 장면·명세서) 스크린샷을 나란히 놓고 사람 눈으로 봄. 예전보다 나빠진 곳 0 |
| A16 ● | **한 문장으로 말하기** | 설명 없이 하루를 해 본 채점자가 "오늘 무엇을 했는지"를 한 문장으로 말할 수 있음. 말하지 못하거나 장면끼리 이야기가 이어지지 않으면 실패 |
| A13 ○ | 폰에서 가벼움 | 입자 수에 상한(코드 상수)이 있고, 폰 녹화에서 눈에 띄게 끊기지 않음 |

## B. 소방서 — 출동 현장 불 끄기 장면

| 번호 | 항목 | 통과 조건 |

| B4 ● | 물이 물처럼 | 물줄기가 입자(방울)로 보이고, 닿는 곳에서 물방울이 튀고 김이 피어오름, 바닥에 젖은 자국이 남음 |

| B7 ● | 기록과 일당 | 소방관 기록이 `place: 'fire-station'`, `job.id: 'firefighter'`, 커리어넷 385, 연 4,000만 원 기준으로 저장되고 `checkRecord` 통과 |

## 채점하는 법 (총괄 Claude)

1. 맡은 쪽이 "끝남 + 커밋 해시 + 고친 것"을 보내면 통합 브랜치에 합쳐요.
2. 채점 에이전트가 이 목록을 처음부터 끝까지 확인하고, 항목마다 통과/실패와 증거를 적어요. 채점 에이전트는 코드를 고치지 않아요.
   - 글자 크기·스크롤 같은 숫자는 **참고**예요. 숫자를 맞추려다 A14~A16이 깨지면 그쪽이 실패예요.
   - 채점 결과로 고칠 것을 보낼 때도 "무엇을 숨기라"가 아니라 "무엇이 학생에게 안 보이거나 헷갈리는지"를 적어요.
3. 필수 실패가 있으면 그 목록만 다시 맡은 쪽에 보내요. 모두 통과하면 선생님께 운영 반영을 여쭤요.
4. 결과는 `shared/BOARD.md` 에 짧게 남기고 현황판을 고쳐요.
