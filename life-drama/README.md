# 인생 드라마

태어난 새벽부터 마지막 별밤까지, 학생이 자기 인생의 길을 직접 걸으며 쓰는 3D 활동입니다.
걷다가 질문을 만나면 답을 적고, 고른 사람들이 곁에서 함께 걷습니다. 끝을 먼저 본 뒤 지금 나이로 돌아와 "이번 주의 한 걸음"을 정합니다.

## 바로 쓰기

`life-drama.html` 파일 하나만 있으면 됩니다. 학생에게 이 파일을 나눠 주거나 웹에 올려 주소를 알려 주세요.
글꼴만 인터넷에서 받아 오고, 인터넷이 없으면 기기 기본 글꼴로 보입니다.

## 구성

| 막 | 내용 |
|---|---|
| 여는 장 | 별명, 옷 색, 머리 모양, 지금 나이 |
| 1막 지나온 길 | 나를 돌봐 준 사람, 빠져들었던 것, 힘들었던 순간 |
| 2막 지금의 나 | 소중한 것 세 가지, 나는 어떤 사람, 곁에 있는 사람 |
| 3막 앞으로의 길 | 인생 계획표(진학·취업·결혼·자녀·은퇴의 나이를 직접 정함), 계획한 사건 장면, 그 사이에 만나는 뜻밖의 질문(만남, 배우고 싶은 것, 큰비, 작별, 사람마다 다른 두 장) |
| 4막 해 질 녘 | 몇 살까지, 마지막 날의 나, 남겨질 사람들에게, 기억되고 싶은 모습 |
| 5막 돌아보기 | 지금 나이로 되돌아오기, 이번 주의 한 걸음, 제목 붙이기 |

완성 화면에서 감상하기, 영상으로 저장, 장면 카드 저장, 대본 고치기, 인쇄, 파일로 보관을 할 수 있습니다.

## 사전 활동지

`인생드라마_사전활동지.pdf`(A4 두 쪽)를 먼저 쓰고 시작합니다. 고치려면 `worksheet.html`을 열어 수정한 뒤 인쇄하면 됩니다.
활동지 3번 인생 계획표의 나이를 화면의 계획표 카드에 그대로 옮겨 적습니다.

## 수업에서 살필 점

- 학생 글은 그 기기의 브라우저에만 저장되고 서버로 가지 않습니다. 함께 쓰는 기기는 끝난 뒤 메뉴의 "처음부터 다시 쓰기"로 지워 주세요.
- 힘들었던 순간, 작별, 마지막 날을 묻는 질문은 모두 건너뛸 수 있습니다. 가족 형태는 정해 두지 않았고 직접 쓸 수 있습니다.
- 수명은 70살 아래로 고를 수 없게 했습니다. 마지막 장면을 어둡게만 쓰는 학생이 있으면 따로 이야기를 나눠 주세요.
- 영상 저장은 감상 화면을 그대로 녹화하므로 재생 시간만큼 걸리고, 그동안 화면을 켜 두어야 합니다. 소리는 녹음되지 않습니다.

## 고쳐 쓰기

```bash
npm install
npm run dev      # 개발 화면
npm run build    # dist/index.html 과 life-drama.html 을 새로 만든다
```

- `src/story.js` 질문 문구와 순서, 등장인물 규칙
- `src/world.js` 하늘빛, 카메라, 길가 풍경 배치
- `src/prefabs.js` 집·나무 같은 풍경 조각
- `src/people.js` 사람과 반려동물
- `src/main.js` 질문 카드와 메뉴, `src/movie.js` 감상·영상·장면 카드

three.js(MIT)를 쓰고, 그림과 모델은 모두 코드로 직접 만들었습니다.
