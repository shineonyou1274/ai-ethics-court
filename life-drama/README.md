# 인생 드라마

태어난 새벽부터 마지막 별밤까지, 학생이 자기 인생의 길을 직접 걸으며 쓰는 3D 활동입니다.
걷다가 질문을 만나면 답을 적고, 고른 사람들이 곁에서 함께 걷습니다. 끝을 먼저 본 뒤 지금 나이로 돌아와 "이번 주의 한 걸음"을 정합니다.

## 바로 쓰기

두 가지 방법이 있습니다.

- **파일 하나로:** `life-drama.html` 하나만 나눠 주면 됩니다. 음악까지 들어 있습니다(약 6MB).
- **웹 주소·QR로:** `site/` 폴더를 통째로 웹에 올리고 그 주소를 QR로 만듭니다. 첫 화면이 빨리 뜨고, 한 번 연 뒤에는 통신이 끊겨도 열리며, 휴대폰 홈 화면에 앱처럼 추가할 수 있습니다. `npm run build:site`로 다시 만듭니다.

시작할 때 학생이 걷는 길이를 고릅니다: 짧게(약 20분), 보통(약 40분), 길게(두 차시). 지금 나이에 따라 중학생·고등학생에게 맞는 질문이 나옵니다.

## 구성

| 막 | 내용 |
|---|---|
| 여는 장 | 별명, 옷 색, 머리 모양, 지금 나이와 나이 기준(만 나이·세는나이) |
| 1막 지나온 길 | 함께 시작한 사람, 4살·7살 무렵의 나 |
| 2막 지금의 나 | 소중한 것, 빠져들었던 것, 힘들었던 순간, 나는 어떤 사람, 곁에 있는 사람 |
| 3막 앞으로의 길 | 인생 계획표(고입·대입·취업·결혼·자녀·은퇴·나만의 사건을 계획함·미정·안 함으로 정하고 나이를 직접 입력) → 계획한 장면 → 갈림길 두 번 → 뜻밖의 질문 |
| 4막 해 질 녘 | 몇 살까지, 마지막 날의 나, 남겨질 사람들에게, 기억되고 싶은 모습, 별자리로 돌아보기 |
| 5막 돌아보기 | 지금 나이로 되돌아오기, 오늘 찍는 점 하나, 제목 붙이기 |

### 매번 달라지는 것, 길 위의 풍경

- 새로 시작할 때마다 갑작스러운 일 세 장(열네 장 가운데)과 갈림길의 사연이 다르게 나옵니다.
- 계획표 아래 "이루고 싶은 일 더하기"에서 집 장만, 자동차 구입, 세계여행, 특허 등록 등을 골라 줄을 더하거나 직접 씁니다(여덟 개까지).
- 이미 지난 입학(중학교·고등학교)은 지나온 길의 장면으로, 앞으로의 입학은 계획표 줄로 나옵니다. 대안학교, 홈스쿨링, 검정고시를 고를 수 있습니다.
- 강을 건너는 다리 세 곳, 갈림길 뒤의 터널, 굽이와 오르내림이 있고 마지막 장면은 언덕 위입니다.
- 세계여행·유학·부모님 여행처럼 ✈ 표시가 있는 일, 뜻밖의 제안에서 "떠난다", 은퇴의 "여행", 대입의 "세상 경험"을 고르면 비행기를 탑니다.
- 배경 음악은 `src/bgm.mp3`(3분, 피아노)이고 빌드할 때 앱 파일 안에 들어갑니다. 곡을 바꾸려면 이 파일을 바꾸고 다시 빌드합니다. 화면 위 ♪ 단추로 켜고 끄며, 메뉴의 "내 음악 넣기"로 다른 곡을 잠시 틀 수도 있습니다.

### 갈림길과 점 잇기

- 답 하나가 길 위의 점(빛) 하나로 남습니다.
- 계획한 진로의 문 앞에서 한 번, 일이 바뀌는 날에 한 번 길이 실제로 세 갈래로 갈라집니다. 고른 쪽으로 길이 휘고, 가지 않은 길은 숲으로 이어진 채 남습니다.
- 갈림길 다음 장면에서 지금까지의 점 가운데 두 개까지 골라 새 길과 잇습니다. 고르면 빛줄기가 이어집니다.
- "한 번 더 도전"이나 "쉬어 가기"를 고르면 그 뒤에 계획한 일들이 한 해 늦어집니다.
- 마지막에 걸어온 장면이 별, 이은 점이 금빛 선, 가지 않은 길이 흐린 가지가 된 별자리를 봅니다.

완성 화면에서 감상하기, 내 별자리 보기, 제출용 한 장, 발표 화면, 지난번과 견주기, 영상으로 저장(일반·2배·4배), 장면 카드 저장, 대본 고치기, 인쇄, 파일로 보관을 할 수 있습니다.

## 사전·사후 활동지

- `인생드라마_활동지_사전.hwpx` (1쪽, 10분): 소중한 것, 나의 꿈, 학업·생활 목표, 인생 미리 그려 보기, 지금 내 마음(다섯 문항).
- `인생드라마_활동지_사후.hwpx` (2쪽): 걸어 본 길, 갈림길에서의 나, 이어진 점, 달라진 나(사전과 견주기), 지금 내 마음(같은 다섯 문항), 길의 끝에서 배운 것, 오늘 찍는 점 하나.
- 사전의 "인생 미리 그려 보기"에 적은 나이를 화면의 계획표에 옮겨 적습니다.
- `인생드라마_사전활동지_고등.hwpx`는 수퍼의 생애진로무지개를 넣은 예전 고등학생용입니다.

## 수업에서 살필 점

- 학생 글은 그 기기의 브라우저에만 저장되고 서버로 가지 않습니다. 함께 쓰는 기기는 끝난 뒤 메뉴의 "처음부터 다시 쓰기"로 지워 주세요.
- 힘들었던 순간, 작별, 마지막 날을 묻는 질문은 모두 건너뛸 수 있습니다. 가족 형태는 정해 두지 않았고 직접 쓸 수 있습니다.
- 수명은 70살 아래로 고를 수 없게 했습니다. 마지막 장면을 어둡게만 쓰는 학생이 있으면 따로 이야기를 나눠 주세요.
- 영상 저장은 감상 화면을 그대로 녹화하므로 재생 시간만큼 걸리고, 그동안 화면을 켜 두어야 합니다. 배경 소리를 켜 두면 함께 녹음됩니다.

## 고쳐 쓰기

```bash
npm install
npm run dev      # 개발 화면
npm run build    # dist/index.html 과 life-drama.html 을 새로 만든다
```

- `src/story.js` 질문 문구와 순서, 등장인물 규칙
- `src/world.js` 하늘빛, 카메라, 길가 풍경 배치
- `src/prefabs.js` 집·나무 같은 풍경 조각
- `src/people.js` 사람과 반려동물
- `src/main.js` 질문 카드와 메뉴, `src/movie.js` 감상·영상·장면 카드, `src/constel.js` 별자리 그림

three.js(MIT)를 쓰고, 그림과 모델은 모두 코드로 직접 만들었습니다.

## 답이 쌓이는 화면

- 질문에 답하면 그 답이 물건이 되어 주인공 머리 위에 나타났다가 길가에 내려앉는다(`story.js`의 `keepKind`, `world.js`의 `setKeeps`). 건너뛴 장면에는 생기지 않는다.
- 완성 화면의 **내 인생 마을**은 답한 것들을 떠 있는 섬 하나에 모아 보여 준다(`village.js`). 길은 섬 가장자리에서 가운데 언덕으로 감겨 들어가고, 제출용 한 장과 인쇄본에도 실린다.
- 점수나 지표는 두지 않는다. 인생에 정답을 매기지 않기 위해서다.
